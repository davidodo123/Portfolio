¿Qué necesita tu negocio?

Dos tipos de webs, un único objetivo: que tu negocio se vea profesional en internet.

Web Estática

Para negocios que quieren presencia online

Una web estática es como un folleto digital siempre disponible. Sin panel de administración ni base de datos — páginas fijas con tu información, fotos y contacto. Perfecta si solo necesitas que la gente te encuentre en internet y vea lo que haces.

  • Diseño completamente a medida, no plantillas genéricas
  • Adaptada a móvil, tablet y ordenador
  • Carga ultra rápida (sin base de datos)
  • SSL incluido (el candado de seguridad en el navegador)
  • Formulario de contacto
  • Optimización básica para aparecer en Google
450 – 500€ pago único
+ 20€/mes gestión en servidor

Web Dinámica

Para negocios que necesitan más

Una web dinámica tiene un motor detrás: base de datos, panel de administración, usuarios, reservas, catálogos... Tú puedes actualizar el contenido sin saber programar. Ideal si necesitas gestionar algo — un catálogo de productos, citas, menús, noticias...

  • Todo lo de la web estática, más...
  • Panel de administración para gestionar contenido
  • Base de datos propia (catálogos, reservas, usuarios)
  • WordPress o Laravel según el proyecto
  • Formularios avanzados, reservas, tienda online
  • Múltiples páginas e idiomas si hace falta
Presupuesto según proyecto
+ 20€/mes gestión en servidor

¿Dónde alojo tu web?

Me encargo de todo lo técnico para que tu web esté siempre online y segura. Utilizo servidores profesionales en Europa con alta disponibilidad y backups automáticos.

Servidor VPS Hetzner o DigitalOcean (EU). Alta disponibilidad y rendimiento real.
Dominio incluido Registro y gestión del dominio .es o .com de tu negocio.
SSL gratuito Certificado HTTPS automático con Let's Encrypt. Seguridad sin coste extra.
Backups semanales Copias de seguridad para que no pierdas nada si algo falla.
Webs estáticas En Vercel o Netlify — gratis y ultra rápidas para webs sin backend.
Soporte continuo Cualquier problema o cambio que necesites, te lo resuelvo.

¿Qué incluyen los 20€/mes?

No es solo "tener la web encendida". Con la gestión mensual me encargo de:

  • Servidor siempre activo y monitorizado
  • Actualizaciones de seguridad automáticas
  • Backups semanales de la web y datos
  • Pequeños cambios de contenido (textos, fotos, precios)
  • Soporte directo por WhatsApp
